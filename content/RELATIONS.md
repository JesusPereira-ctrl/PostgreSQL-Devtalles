# Relations

## Type of relations and examples with real life

- One To One: Example One student has one contact info
- One To Many: Example One customer has many orders
- Self Joining Relationships: Example One user can be modified by other user or the same user and users are in the same table
- Many To Many: Example Many students can have many classes and many classes have many students, in this case the people says the relation many to many doesn't exist, this happens because the relation is created by a intermediate table in many cases which references both tables in a record to establish the relationship
