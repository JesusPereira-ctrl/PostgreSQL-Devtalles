# Keys

## Type of Keys

- Primary Key
- Super Key
- Candidate Key
- Foreign Key
- Composite Key

There are more, and all the keys serve to identify records.

Among others: Alternate Keys, Artificial Keys

## Primary Key

- Identifies a record uniquely
- A table can have several unique identifiers
- The primary key is based on the requirements

## Candidate Key

- An attribute or set of attributes that uniquely identify
- Excluding the primary key, the others are considered candidate keys

## Super Key

- It is a set of attributes that can uniquely identify.
- It is a superset of a candidate key.

## Foreign Key

- Foreign keys are used to point to the primary key of another table.
- The ID that will be referenced in the other table must have the same data type and length to ensure compatibility.

## Composite Key

- When a primary key consists of more than one attribute, it is known as a composite key.
