# Database General Information

## ¿What is a data base?

A data base is a structured collection of organized information and stored semantically in a database management system (SGDB)

## The way information is stored makes a difference: SQL vs NoSQL

- SQL: When we talk about SQL databases, we are referring to a structured way of storing data in the form of rows and columns (similar to Excel).
- NoSQL: When we talk about NoSQL databases, we are referring to a way of structuring data that is less rigid—typically in JSON format, using key-value pairs within documents.

## Candidates of SQL

- SQL Server
- PostgreSQL
- MySQL

## Characteristics of SQL

- SQL means Structured Query Language
- All relational databases execute queries in a similar way.
- Predefined schemas: Before using them, tables are created in advance with the structure that will be used.
- Consistency: The focus is on ensuring the integrity and consistency of information.
- Storage: Data is recorded in tables, with records in rows—also referred to as entities and attributes.
- Indexes: Primary keys, foreign keys, composite, indexes, etc., enhance transaction speed.

## Candidates of NoSQL

- Cloud FireStore
- MongoDB
- CassandraDB
- Redis

## Characteristics of NoSQL

- Storage: Information is stored in objects—commonly referred to as documents—which are organized into collections; these objects are in JSON format.
- Flexible Schema: It is not rigid; you can create documents and collections without having to define them.
- Focus: Performance, horizontal scalability, speed, and availability
- Fault tolerance: great flexibility allows for high fault tolerance and the handling of null or non-existent values.

## ¿Who is best?

There is no single definitive answer; it depends on the intended use, flexibility, and your vision and mission. There are no specific restrictions that would prevent you from choosing either SQL or NoSQL.
